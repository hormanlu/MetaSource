# 旧版本素材库

本目录保存第一版（master 分支，16 章）与第二版（new 分支，重构停摆）的历史素材，供**后续创作时查阅、复用灵感、核对前作事实**。本目录所有内容**不属于新仓真源**，真源请以 `00-项目总纲/` / `01-世界观/` / `02-人物/` / `03-剧情/` / `04-连续性账本/` 为准。

## 使用原则

- **只读**：不要在这里写新内容，想抽取的内容改造后放入真源对应目录
- **不自动同步**：真源发生变化不要回流到这里
- **命名可读**：全部中文命名，方便语义检索
