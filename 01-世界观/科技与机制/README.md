# 科技与机制

存放 EarthOL 世界中的技术设定、系统机制、工具与道具。一项一卡。

## 分类建议

- `系统机制/`：异常检测、清理链、引擎映射等底层机制
- `技术/`：觉醒者侧或民间侧的工具、装置
- `道具/`：具体出场的关键物品

## 卡片模板（frontmatter）

```yaml
---
类型: 科技 | 机制 | 道具
层级: 真源 | 觉醒者工作模型
别名: []
首次出现: ""
状态: 生效
---
```

## 必含字段

- 功能
- 运作原理（严格区分"作者真相" vs "觉醒者工作模型"）
- 代价或副作用
- 谁能使用 / 谁能识别
- 叙事用途（适合承载什么冲突）

## 关键约束

- 觉醒者的引擎映射解释默认为"工作模型"，不得在正文被写成作者盖章的真相
- 任何新机制必须登记到 `01-世界观/术语表.md` 与 `04-连续性账本/事实账本.md`
