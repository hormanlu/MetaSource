# MetaSource

`MetaSource` 是一个以代码仓库方式管理的原创中文科幻 IP 项目（世界内产品名 `EarthOL`，暂定中文名 `源码宇宙`）。

目标不是直接"开写一切"，而是建立一套适合长篇小说、世界观管理、章节续写、设定审校和衍生内容生产的 AI 工作流，让创作尽量不跑偏。

---

## 仓库目标

- 为 `MetaSource / EarthOL / 源码宇宙` 维护长期可复用的世界观资产
- 用结构化文件替代口头记忆，降低 AI 长文失忆、设定漂移和人物跑偏
- 为小说、短视频、人物外传、设定解读等衍生内容提供统一真源
- 把"创作"拆成可追踪的阶段：规划、写作、审校、回填、迭代

## 从哪里开始

每次开始一个新会话或新任务，先读：

1. `AGENTS.md`
2. `00-项目总纲/项目简述.md`
3. `01-世界观/硬规则.md`
4. `00-项目总纲/当前焦点.md`

章节任务再读对应的 `05-正文/第N卷/第NNN章/` 下的 `简报.md`、`章纲.md`、`草稿.md`。

## 目录说明

### 00-项目总纲

项目级元信息：项目定位、当前焦点、路线图。

### 01-世界观

世界观真源。`硬规则.md` 优先级最高，`世界设定.md` 次之，`术语表.md` 定义标准名。子目录 `地点/`、`派系/`、`科技与机制/` 一项一卡。

### 02-人物

角色卡真源。一人一卡，按 `主角/`、`配角/`、`反派与组织人员/` 分类。`_模板.md` 提供带 frontmatter 的标准卡。

### 03-剧情

剧情真源 + 方法论视图。`系列主线.md`、`卷纲/` 是真源；`方法论/` 下的七点法、雪花法、救猫咪、故事网格只是工作视图。

### 04-连续性账本

7 份真相文件，**防 AI 长文失忆的核心层**：

- `事实账本.md` — 已成立的硬事实
- `时间线.md` — 已发生事件的先后
- `伏笔账本.md` — 待回收伏笔
- `人物知识矩阵.md` — 谁在什么时候知道什么（防角色全知）
- `支线看板.md` — 未完结支线状态
- `情感弧线.md` — 主要角色情感变化
- `章节摘要.md` — 每章 2-5 行摘要（AI 续写的核心上下文）

### 05-正文

小说正文生产区。每章一个目录，标配 `简报.md + 章纲.md + 草稿.md` 三件套。

### 06-文风

`散文风格.md` 描述"中文小说应该怎么写"，`去AI味.md` 描述"要避免什么"。

### 07-衍生内容

预留占位目录。主线稳定前不填充。

### 08-调研素材

`开源参考.md` 列出本仓库参考的开源项目（Obsidian Loreteller、InkOS、Scrivener、novel-writer-cn 等），`资料/` 存外部资料。

### 09-工作区

生产性工作区：`灵感/`、`提案/`、`评审/`、`归档/`（软删除仓）。任何设定改动先走 `提案/` 审议，合并前不进入真源。

### ._agent/（AI 编排层）

所有 AI 协作的内部资产，与"给人读的真源"分离：

- `意图路由.md` / `工作流路由.md` — 自然语言 → 内部意图 → 最小调用链
- `编排/` — 中控、智能体清单、上下文装配、单章流水线
- `技能/` — 8 份技能定义（编排中控、世界设定师、角色设计师、章纲设计师、章节续写师、一致性审校员、文风精修师、账本维护员）
- `提示词/` — 会话启动、章节前置简报、审校门禁、事实回填
- `审计维度.md` — 审校五维（A 一致性 / B 人物 / C 剧情 / D 文风 / E 风险升级）
- `状态/会话日志.md` — 会话记忆压缩
- `写完一章.md` — 强制检查清单（7 账本 + 快照 + 焦点更新）

### AGENTS.md

项目宪法。跨 IDE 通用，定义所有 AI 协作的默认必读 / 禁止行为 / 强制工作流。

## 推荐工作流

1. 明确任务类型：设定 / 人物 / 剧情 / 正文 / 审校 / 精修
2. 按 `AGENTS.md` 加载必要上下文（遵循 `._agent/编排/上下文装配.md`）
3. 如果任务较复杂，按 `._agent/编排/单章流水线.md` 的八阶段执行
4. 在 `05-正文/` 或 `09-工作区/提案/` 对应位置工作
5. 用 `._agent/提示词/审校门禁.md` 做自检
6. 写完一章执行 `._agent/写完一章.md` 强制清单（7 账本回填 + Git tag 快照）
7. 更新 `00-项目总纲/当前焦点.md` 与 `._agent/状态/会话日志.md`

## 编排入口

如果任务涉及多步创作或需要多技能分工，优先读取：

1. `._agent/编排/中控.md`
2. `._agent/编排/智能体清单.md`
3. `._agent/编排/上下文装配.md`
4. `._agent/编排/单章流水线.md`

默认调用链：

- 设定任务：编排中控 → 世界设定师 → 一致性审校员
- 人物任务：编排中控 → 角色设计师 → 一致性审校员
- 章节任务：编排中控 → 章纲设计师 → 章节续写师 → 一致性审校员 → 文风精修师 → 账本维护员

## 写入权限速查

- **允许直接写入**：`05-正文/**`、`09-工作区/**`、`._agent/状态/**`
- **受限写入**：`04-连续性账本/**`（仅账本维护员回填）
- **禁止直接写入**：`01-世界观/**`、`02-人物/**`、`03-剧情/**`（必须走 `09-工作区/提案/` 审议）

## 参考蓝本

本仓库目录与工作流融合了以下开源实践（详见 `08-调研素材/开源参考.md`）：

- Obsidian Loreteller 指南 — frontmatter / 一实体一文件 / 别名
- InkOS — 七份真相文件 / 快照改写 / 强制回填
- Scrivener — Trash 软删除 / Front Matter 分离
- novel-writer-cn — AI 编排层隔离 / 阶段锁定产物
- novelWriter — 纯文本 + 跨文件索引
- 雪花法第 8 步 / Save the Cat 15 拍 / Story Grid 场扫描 / 七点法
