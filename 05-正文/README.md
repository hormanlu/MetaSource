# 正文

小说正文生产区。

## 目录约定

- 一卷一目录：`第一卷/`、`第二卷/` ……
- 一章一目录：`第001章/`、`第002章/` ……（三位数字前缀留扩展位）
- 每章目录内三件套：`简报.md`、`章纲.md`、`草稿.md`
- 可选追加：`审校.md`、`精修.md`、`修订日志.md`

## 章节目录命名

- 正式章：`第NNN章/`
- 实验章/待定章：`_第NNN章/`（下划线前缀，默认跳过构建、导出）
- 被砍章：移入 `09-工作区/归档/` 而不是 `git rm`

## 章节生产流程

详见 `._agent/编排/单章流水线.md`，标准链路：

> 任务识别 → 上下文装配 → 章纲校准 → 草稿生成 → 一致性审校 → 文风精修 → 回填账本 → 门禁决策

## 章节 frontmatter 标准

每章的 `草稿.md` 建议包含以下 frontmatter：

```yaml
---
类型: 章节草稿
卷: 1
章: 1
标题: "待定"
POV: "[[林默]]"
状态: planned | drafting | drafted | reviewed | polished | final
字数: 0
场景数: 0
关联章纲: "章纲.md"
关联简报: "简报.md"
---
```
