# 变更影响分析（强制）

本文件定义当“真源”发生变更时，AI 必须执行的影响面分析流程。

适用范围（真源）：

- `01-世界观/**`
- `02-人物/**`
- `03-剧情/**`

目标：

- 在新对话缺少上下文提示时，也能通过仓库结构与规则自动触发“影响面扫描 + 同步修改/登记”。
- 避免只改了人物卡/设定，却忘记同步章节、账本与依赖文件。

## 0. 前置读取（强制）

- `README.md`
- `AGENTS.md`
- `00-项目总纲/项目简述.md`
- `01-世界观/硬规则.md`
- `00-项目总纲/当前焦点.md`
- `._agent/状态/待同步变更.md`

## 1. 变更分类（先定类，再动笔）

将本次改动归入一个或多个类别（用于决定扫描范围）：

- A. 措辞/表达（不改事实）
- B. 行为逻辑（可能影响章节行为）
- C. 能力口径（影响机制与冲突代价）
- D. 关系结构（影响人物关系与知识边界）
- E. 时间线/事实（影响账本）
- F. 术语/命名（影响全仓引用）
- G. 生死/阵营/重要性（高影响）

## 2. 受影响文件清单（强制输出）

至少输出以下三段清单：

1. 必须同步（本轮一起改）
2. 建议同步（可分批，但必须登记）
3. 仅需关注（不改也可，但需确认无冲突）

清单生成方法：

- 以“标准名 + 别名 + canon_id + 关键术语”做全仓检索
- 对照下列目录逐层检查

扫描范围（按类别扩展）：

- 固定范围（总是扫）：
  - `05-正文/**`（章节三件套、定稿片段）
  - `04-连续性账本/**`（至少：事实账本、时间线、人物知识矩阵、章节摘要）
  - `09-工作区/提案/**`、`09-工作区/评审/**`（若存在相关提案/评审）
- 变更为术语/命名（F）时，必须额外扫：
  - `01-世界观/术语表.md`
- 变更为能力口径（C）时，必须额外扫：
  - `01-世界观/科技与机制/**`
  - 相关人物档案目录（若有）
- 变更为时间线/事实（E）时，必须额外扫：
  - `04-连续性账本/事实账本.md`
  - `04-连续性账本/时间线.md`
  - `04-连续性账本/伏笔账本.md`
- 变更为关系结构/知识边界（D）时，必须额外扫：
  - `04-连续性账本/人物知识矩阵.md`
  - `04-连续性账本/情感弧线.md`

## 3. 待同步登记（强制）

如果本轮不打算同步所有受影响文件，必须把未完成项写入：

- `._agent/状态/待同步变更.md`

登记字段至少包括：

- 变更主题（例如：温启山能力口径）
- 变更类别（A-G）
- 已同步文件
- 待同步文件
- 风险说明（漏同步会导致什么）

## 4. 完成条件（门禁）

真源变更任务只有在满足以下条件时才算完成：

- 输出“受影响文件清单”
- 已同步“必须同步”项，或全部登记到待同步清单
- 无硬规则冲突
