# 第一章 窗外异样（定稿）

下午四点十七分，林默站在公司十七楼的落地窗前，指尖轻轻揉着发酸发涩的眼周。连续几周的加班，疲惫像细密的藤蔓缠上眼眶，酸胀感一波波涌来，直到指尖按在太阳穴上缓缓打圈，那股沉重的疲惫才稍稍褪去几分。

对面矗立着未来科技大厦——这座城市的科技地标，六十层的玻璃幕墙在夕阳下泛着冷冽的光泽，像一块被精心切割的巨大蓝色水晶，将落日余晖裁成细碎的金斑，零零散散洒在楼下川流不息的街道上。楼顶上那块巨型LED广告牌，正不知疲倦地循环播放着他们的广告语：We Build The Future，蓝底白字，字体规整而遒劲，每隔十秒便准时切换一次，即便在明亮的白日里，也透着几分不容忽视的刺眼。

这画面，林默看了整整三年。未来科技是行业内毋庸置疑的巨头，业务版图横跨游戏、AI、云计算、社交等多个大领域，市值早已突破数千亿，是无数技术人梦寐以求的归宿。他们团队里，曾经有三个前同事先后跳槽到了那里，偶尔翻到他们朋友圈里分享的工作日常，林默心底的羡慕便忍不住翻涌上来。

去年，林默也曾托其中一位前同事内推过简历，可接连两三周都石沉大海，杳无音信。最后，他还是厚着脸皮请前同事帮忙打听结果，得到的反馈却像一盆冷水，浇得他透心凉：工作年限与能力不匹配。说白了，就是他在游戏客户端技术开发领域的经验尚浅，整体性价比达不到对方的要求。

“确实是经验不足。”林默自嘲地勾了勾嘴角。他今年已经三十岁，从本科毕业便一头扎进游戏行业，算下来也有近六年的工作经验。指尖无意识地摩挲着落地窗的玻璃，冰凉的触感顺着指尖蔓延开来，让混沌的大脑稍稍清醒了些。他的目光从对面的未来科技大厦收回，扫过眼前这间开放式办公区，心底泛起一阵难以言喻的无奈。

这里是星辰互娱的十七层，林默所在的《星际OL》项目组，于2021年正式立项。彼时恰逢元宇宙风口，老板拍着桌子定下目标，要做“中国版的《第二人生》”。一百多人的团队，耗费三年光阴，砸进去数千万预算，最终只进行过一次小规模内部测试——五千个测试名额，服务器却接连崩了三次，反馈清一色的差评：“连走路都走不顺畅。”

预算，一夜之间归零。

2024年春节过后，第一波裁员如期而至。主程被裁，主策被开，美术团队更是整建制解散。林默至今还记得那天的场景：HR一个个叫人进会议室，出来的人里，有的红着眼眶沉默不语，有的忍不住当场暴怒斥责，还有的抱着装满个人物品的纸箱，蹲在消防通道里默默抽烟，眉眼间满是不甘与茫然，藏着被现实击碎的狼狈。

转眼到了2025年底，曾经一百多人的团队，硬生生裁得只剩五个人：林默负责客户端开发，老王管服务器运维，还有两个美术负责基础维护，一个运营身兼策划与客服数职，一人多劳，勉强撑着这个濒临解散的项目。

如今的状态，说是维护，不如说是耗着——只有内部测试服，没有正式服，没有真实玩家，服务器就那样空转着，没有任何更新迭代，唯有老板偶尔会来露个面，画一张虚无缥缈的饼，说等市场调研确定了新方向，就重启项目。林默心里跟明镜似的，这不过是稳住他们的借口罢了。他偶然听说，老板最近要去挪威看极光，或许等老板回来，这个苟延残喘的项目，就会迎来最终的结局。

现在已经是2026年3月了，挪威还会有极光吗？乱七八糟的消息搅在一起，林默早就分不清哪句是真，哪句是假了。

作为客户端开发，林默主要负责《星际OL》客户端的日常维护。这款游戏是用UE引擎开发的，只因立项较早，至今仍沿用着UE4版本。最近这段时间，他一直在潜心研究最新的UE5.7的World Partition功能，想着用这套方案重构《星际OL》的架构，彻底解决之前内部测试时频繁出现的卡顿、闪退、掉线等问题。

他心里其实很清楚，项目早已是强弩之末，这么做，或许能为项目争取一丝重启的可能，但更多的，是为了他自己。技术债终究要还，可更重要的是，他想借着这个机会，积累客户端大世界开发的实战经验——上次内推未来科技失败，症结就在于他缺少一套系统的、能独当一面的核心能力。若是能把这套架构成功复刻出来，哪怕项目最终还是关停，写进简历里，也是实打实的硬通货，下次跳槽时，也能多一份底气，谈个更好的薪资。

“林默，”老王端着一杯温热的咖啡从旁边走过，在他工位旁停下，声音压得不算低，“你申请的二十台服务器，江月让你过去一趟，聊聊这事。”

老王本名王建国，今年四十六岁，在星辰互娱已经待了十几年，是当前团队里年纪最大的，也是唯一一个从项目创立之初坚持到现在的老员工。他见证过项目立项时的意气风发，也熬过裁员潮的冷清萧瑟，如今活成了项目组的“吉祥物”——资历老，薪资不算高，对项目的每一个细节都了如指掌，若是换个人接手，成本恐怕比留下他更高。老王的心态极好，每天按时上下班，午休时雷打不动要玩几局《皇者荣耀》，用他的话来说：“既然早晚要死，那就死得舒服点，犯不着跟自己较劲。”

“知道了。”林默站起身，随手理了理身上皱巴巴的格子衫，朝着运维总监办公室的方向走去。

江月坐在办公室里，面前放着一台笔记本，盖子已经合上。办公室的墙上，挂着三块巨大的显示屏，屏幕上密密麻麻布满了各种监控图表，跳动的数据无声地诉说着公司各项资源的运行状态。她是三个月前刚从未来科技挖过来的，对“运行异常”有着近乎本能的敏锐直觉。老板当初在全公司发了任命邮件，特意让她重新梳理全公司的资源盘点，负责成本审计工作。

“江总监，”林默轻轻敲了敲门，语气带着几分拘谨，“您找我，是关于服务器申请的事……”

江月抬眸看来。她三十出头，留着利落的短发，眉眼清冷，脸上没有多余的表情，眼神锐利得仿佛能穿透人心，让人不自觉地心生敬畏。

“二十台？”她微微皱起眉头，声音带着一丝不易察觉的沙哑，“《星际OL》现在是什么状态，你应该清楚——只有内部测试服，没有真实玩家，CPU利用率常年不到5%，五台物理机都绰绰有余，你申请二十台新服务器，用来做什么？”

“我想重构游戏的大世界架构，”林默连忙解释，语速不自觉加快，“用UE最新的World Partition功能，把地图分成多个Grid，实现数据分层、按需加载，这样就能彻底解决之前内部测试时的加载卡顿、掉线问题，而且……”

“你先等一下。”江月打断了他的话，语气没有丝毫缓和，“业务怎么推进，我不关心，我只看资源利用率，只看实际价值。你们组现在还有五台物理机，用来跑你们这个空转的内部测试服，都已经是一种浪费了，为什么还要多申请十五台？”

林默愣了一下。他原本以为，江月从未来科技过来，必然是懂技术的，能听懂他说的架构层面的考量，没想到她直接切入资源监控的实际角度，丝毫不讲情面，还莫名将他申请的数量缩减到了十五台。

“而且，这能节省长期成本。”林默避开她锐利的目光，语气稍稍放缓，“新架构搭建完成后，同样的在线人数，只需要现在一半的服务器资源，长期来看，能帮公司省下不少开支。”

江月沉默了几秒，指尖在光滑的桌面上轻轻敲击着，节奏均匀，却透着一股无形的压迫感。

“行吧。”她最终点了点头，语气依旧冷淡，没有丝毫松动，“这样，你先写一份详细的技术报告给我。内容包括架构设计方案、资源占用预估、新旧成本对比，还有——最重要的一点——如果项目下周就关停，你申请的这些服务器该如何处理，怎样才能将损失降到最低。写清楚了，我们再谈后续。”

林默苦笑了一下，试探着问道：“江总监，您觉得……这个项目下周会关停吗？”

“那你觉得呢？”江月没有直接回答，反而将问题抛回给了他，语气冷得像冰，没有一丝温度。

回到工位，林默打开了UE5.7编辑器。屏幕上显示的是《星际OL》的内部测试场景：一片光秃秃的草地，几棵模型粗糙的树木零散分布，远处的山脉做了低模糊处理，显得模糊不清，整幅画面毫无生气，像一片被遗忘的荒原。

他盯着屏幕看了几秒，突然有些恍惚——这个项目，就像他手里的一颗死棋，明知道没有赢的可能，却还是要死死守着，哪怕只是为了给自己多争取一点跳槽的筹码。

他甩了甩头，将那些杂乱的情绪驱散，指尖落在键盘上，开始敲击代码。代码写得差不多，准备提交测试时，他习惯性地瞥了一眼窗外——

广告牌上的广告语，好像变了？

原本的We Build The Future，不知何时，竟变成了We Control The Future。依旧是蓝底白字，字体、颜色、大小都和之前一模一样，没有任何差别，唯独中间的动词，从“Build”换成了“Control”。那个“C”字母格外醒目，在夕阳的映照下，泛着冰冷的光，像一只无形的眼睛，死死地盯着他，让他浑身一僵，一股寒意顺着脊背爬了上来。

林默眯起眼睛，下意识地凑近落地窗，鼻尖几乎要碰到冰凉的玻璃。广告牌上的字清晰无比，没有任何模糊或卡顿，绝不像幻觉。他用力眨了眨眼，再次望去——

字，又变回了We Build The Future。

“幻觉？”林默喃喃自语，指尖再次按在太阳穴上，用力揉了揉。连续加班一周，昨晚只睡了四个小时，或许，真的是眼花了，是过度疲劳产生的错觉。

他转过身，看向旁边正低头刷手机的老王，语气里带着一丝不确定：“老王，你看对面广告牌上的字，是什么？”

老王闻言，漫不经心地抬起头，瞥了一眼窗外，随口答道：“We Build The Future啊，还能是什么？怎么了，你看错了？”

“没什么，”林默摇了摇头，将心底的疑惑压了下去，“可能是我眼花了，刚才好像看到，中间的词变了。”

“变了个词？”老王笑了笑，从口袋里摸出一颗薄荷糖，扔给林默，“你这几天熬夜熬傻了吧？连续这么高强度加班，出现幻觉太正常了。早点回去休息，项目要死就死，人可不能跟着猝死，不值得。”

林默接过糖，没有剥开，只是捏在手里，指尖传来糖纸褶皱的粗糙触感。他犹豫了一下，又问道：“老板今天又提项目关停的事了？”

“好像是，我也是从以前的同事那里听来的。”老王压低了声音，语气里带着一丝无奈，“说这项目搁置太久了，要重新review一下。我们也得提前做好准备，该找下家的赶紧找下家，别到时候手忙脚乱。听说老板这周出差了，下周回来，估计就有准信了。咦，不是说老板去看极光了吗？算了，老板到底去哪、什么时候回来，真真假假的消息搅在一起，林默早就懒得去分辨了。”

林默没有说话，心底泛起一阵酸涩。项目关停是早晚的事，他早就有了心理准备，只是有些可惜——他刚申请了服务器，还没来得及正式测试，项目可能就没了。而且那个广告牌的变化，他总觉得，不像是单纯的幻觉，但老王说得对，或许，真的是自己太累了。

“对了，”老王站起身，拍了拍他的肩膀，语气轻快了些，“晚上要不要一起吃饭？楼下新开了家麻辣烫，第二份半价，我请你。”

“不了，”林默把糖放进衣兜，摇了摇头，“今天周三了，我还得写技术报告，早点写完，争取这周能交给江月。服务器申请的事，得写得详细点，才有可能批下来，毕竟是我要用，也不能麻烦你。”

“行吧，”老王摆了摆手，端着茶杯转身走了，走之前还不忘回头叮嘱一句，“别太拼了，真的不值得。”

林默坐回椅子上，重新看向电脑屏幕，可心思却总是不受控制地飘到窗外。他再次抬头，望向对面的广告牌——依旧是We Build The Future，蓝底白字，每隔十秒准时切换一次，和过去三年里的每一天一样，和今天之前的每一秒一样。那个短暂出现的“Control”，仿佛从未存在过，就像一场转瞬即逝的幻觉，消散得无影无踪。

他打开文档，开始撰写那份技术报告。不是为了老板画的空头大饼，不是为了让这个半死不活的项目重启，只是为了他自己，为了能顺利跳槽——这大概是他在《星际OL》这个濒临落幕的项目里，能拿到的最后一份有价值的技术资产了。

但他不知道的是，在未来科技大厦的某个机房里，一串冰冷的系统日志刚刚被自动清除，没有留下任何痕迹：

系统提示：检测到广告显示模块异常，已自动修复。无系统稳定性影响。
