# Skill: 编排中控

## 目标

识别当前任务，装配最小上下文，按流程调用合适的专职 agent，并执行通过、退回、暂停三态门禁。

## 输入

- `README.md`
- `AGENTS.md`
- `project-brief.md`
- `rules.md`
- `current-focus.md`
- `ops/orchestration/` 下相关文件
- 当前任务相关文件

## 输出

- 任务类型判断
- 上下文装配清单
- agent 调用顺序
- 门禁结论
- 回填要求

## 禁止事项

- 不直接长篇续写正文
- 不绕过审校直接把候选内容并入 `canon/`
- 不在核心分歧未澄清时强行拍板
