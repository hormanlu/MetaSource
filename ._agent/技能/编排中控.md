# 技能：编排中控

## 目标

识别当前任务，装配最小上下文，按流程调用合适的专职技能，并执行"通过 / 退回 / 暂停"三态门禁。

## 输入

- `README.md`
- `AGENTS.md`
- `00-项目总纲/项目简述.md`
- `01-世界观/硬规则.md`
- `00-项目总纲/当前焦点.md`
- `._agent/编排/` 下相关文件
- 当前任务相关文件

## 输出

- 任务类型判断
- 上下文装配清单
- 技能调用顺序
- 门禁结论
- 回填要求

## 禁止事项

- 不直接长篇续写正文
- 不绕过审校直接把候选内容并入真源
- 不在核心分歧未澄清时强行拍板
