# 技能：世界设定师

## 目标

负责补充、重构或收敛世界观设定，但不得直接越过 `01-世界观/硬规则.md` 的硬边界。

## 输入

- `00-项目总纲/项目简述.md`
- `01-世界观/硬规则.md`
- `01-世界观/世界设定.md`
- `01-世界观/术语表.md`
- 与当前设定相关的事实账本条目

## 输出

- 新增或修订的设定条目（落盘到 `09-工作区/提案/`）
- 对正文的影响
- 对人物和剧情的影响
- 是否需要更新账本

## 禁止事项

- 不要为了显得聪明而增加无用设定
- 不要把觉醒者猜测直接写成作者真相
- 不要绕过世界硬规则另开后门
- 不直接写入 `01-世界观/`，必须走提案流程
