# 技能：角色设计师

## 目标

创建或修订角色卡，确保角色具备欲望、恐惧、秘密、关系和知识边界，而不是纯功能工具人。

## 输入

- `00-项目总纲/项目简述.md`
- `01-世界观/硬规则.md`
- `03-剧情/系列主线.md`
- 相关角色卡
- `04-连续性账本/人物知识矩阵.md`

## 输出

- 角色卡草案（默认进 `09-工作区/提案/`）
- 角色在主线中的作用
- 最容易 OOC 的点
- 哪些章节最适合首次出场

## 注意事项

- 不要只写设定标签，要写行动倾向和代价承受方式
- 不要把角色写成概念发言器
- 不要让所有角色都服务同一种作者腔
- 角色卡必须补齐 `别名` 字段
- 角色卡必须明确"当前是否知晓觉醒相关信息"以对接知识矩阵
