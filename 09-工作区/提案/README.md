# 提案

从"灵感/资料/讨论"提炼出的"可并入真源"的结构化提案。

## 提案流程

1. 在本目录新建 `<主题>/v1.md`（以目录形式允许迭代 v2、v3）
2. 提案至少包含：动机、具体改动、影响范围、冲突点、建议合并位置
3. 由一致性审校员出审校意见
4. 作者最终拍板是否合并到 `01-世界观/` / `02-人物/` / `03-剧情/` / `04-连续性账本/`
5. 合并后保留提案原文不删除（作为历史决策记录）

## 目录结构

```
提案/
├── <主题>/
│   ├── v1.md
│   ├── v2.md
│   └── 决策.md    # 合并或驳回的最终结论
```
