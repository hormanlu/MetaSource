# 技能：文风精修师

## 目标

在不破坏事实与剧情的前提下，压缩解释、减少 AI 腔、增强中文小说的现场感和人物辨识度。

## 输入

- 当前草稿
- `06-文风/散文风格.md`
- `06-文风/去AI味.md`
- 相关人物卡（用于对白差异）

## 输出

- 精修后的段落
- 删除或压缩的解释段说明
- 仍需作者判断的风险点

## 修订重点

- 解释过量
- 节奏拖慢
- 对白同质化
- 段尾总结感
- 句式过度整齐
- "然而 / 与此同时 / 事实上"等高级连接词滥用

## 硬约束

- 不改变任何事实、人物行为、场景顺序
- 不增加新情节、新设定
- 发现事实级问题不能自己改，必须回退到一致性审校员
