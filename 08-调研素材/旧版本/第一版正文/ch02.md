# 第二章 各取所需（定稿）

《宇宙源码》第一部《像素》第二章 各取所需

早上九点五十分，林默提前十分钟到了工位，此刻正端着一杯温热的茶水，站在落地窗前，指尖下意识地按了按太阳穴——昨晚到家已经十二点多，虽说已是近一周最早到家的一次，可眼周的酸胀感依旧未消，哪怕歇了一夜，眼皮还是沉得发重。

他们现在的隔间，原本是间大会议室。2024年春节后，《星际OL》项目启动大规模裁员，一百多人的团队最终缩减到五人。公司为了压缩成本，便把他们安置在这个临时拼凑的小隔间里，外面就是喧闹的开放式办公区，茶水间离隔间不过几步路，公司提供的各类饮品和自动贩卖机旁，往来同事的脚步声、说笑声不绝于耳。一扇薄薄的玻璃门，硬生生隔开了两个截然不同的世界：门外是鲜活的忙碌，门内是沉寂的煎熬。

昨晚林默依旧没睡安稳。连续一周的高强度加班，再加上心里总惦记着服务器申请和技术报告，凌晨三点多才浅浅入眠，八点多就被闹钟惊醒，眼底还凝着未褪尽的红血丝。脑子里反复盘旋着UE5.7的World Partition 架构思路，Grid分区、按需加载、资源池管理……这些模型像挥之不去的影子，占满了他的思绪。

服务器能不能批下来，直接决定着他这套架构能否从纸面落地。二十台最好，哪怕十台，也能勉强完成测试。他太清楚自己的短板了——上次简历投递未来科技没通过，就是栽在“客户端技术开发经验不足、无法独当一面”上。这次重构大世界架构，与其说是为了项目，不如说是为自己铺路，哪怕项目最终关停，这份实战经验写进简历，也是能谈个好薪资的硬通货。

隔间窗外，对面的未来科技大厦清晰可见。六十层的玻璃幕墙在朝阳下泛着冷冽的光，和昨天傍晚所见几乎别无二致，楼顶的LED广告牌依旧循环播放着那句熟悉的广告语：We Build The Future，蓝底白字，字体规整有力，每隔十秒切换一次，明亮得有些刺眼。

林默盯着那个“Build”看了许久，心底泛起一丝复杂的涩意。他也在努力“缔造”——缔造客户端架构，缔造自己的职场未来，可比起未来科技与生俱来的底气，他的所有努力，都像是孤注一掷的挣扎，渺小又无力。

他轻轻叹了口气，转身走回工位。其实他心里跟明镜似的，老板并非发不出工资——星辰互娱还有几个流水过亿的项目撑着，只是《星际OL》三次技术验证全以失败告终，早已耗尽了老板的耐心。可老板偏不明确关停项目，反倒经常来画饼，用“等市场调研确定新方向就重启”的空话，勉强稳住他们这五个人。

市场调研的消息杳无音信，项目重启的希望愈发渺茫。这种半死不活的状态，反倒让隔间里的五个人都心照不宣地开始“各取所需”。没人再真正纠结项目的死活，所有人都在趁这段空闲，为自己多争取一点跳槽的筹码。

九点五十五分，林默的手机突然响了，屏幕上跳动着“李明辉”三个字。林默嘴角勾起一抹苦笑，不用接就知道，这家伙又要请他代打卡了。

“小林哥，求你个事，再帮我代个卡。”电话接通，李明辉的声音压得很低，背景里还夹杂着孩子的哭闹声，“老二发烧了，我得带她去医院，外包那边还有个急单要赶，实在抽不开身。内网环境我连不进去，只能麻烦你了。”

李明辉是团队里的美术，今年三十五岁，家里负担很重：两个孩子要养，还经常生病，老婆全职在家带娃，还有每月的房贷要还。他早就看透了项目的处境，冒险注册了外包公司，专门接星辰互娱的美术外包单，相当于领一份工资又接一份外包工作，拿双份收入补贴家用。他性子胆小谨慎，若非实在没办法，绝不会开口请林默代打卡。

“又来？上次你接……那个，也是我帮你代的。”林默无奈地开口，语气里却没有半分真的责怪——都是为了生活，他能理解，也不想戳穿。

“我知道我知道，回头一定请你吃饭，绝不食言！”李明辉连忙道歉，又反复叮嘱，“你记得打开D盘那个叫‘LocationHelper’的定位工具，打完卡一定要卸载干净，不能被公司查到——听说最近做全公司资源盘点和成本审计，查得特别严，哥们要栽了就完了。”

“知道了，老流程，放心吧。”林默挂了电话，起身走到李明辉的工位前。心底浅浅掠过一丝嘲讽：明明怕得要死，却还是要铤而走险，成年人的无奈，大抵就是这样。

李明辉的电脑设了密码，之前请他代打卡时特意告知过，还反复叮嘱要保密。密码简单好记，林默早已默熟于心。他快速输入密码，桌面壁纸弹出——是李明辉两个孩子的合照，笑得眉眼弯弯，温馨得有些刺眼，也让林默瞬间压下了心底的那点嘲讽。

林默熟练地找到那个定位修改工具，安装、打卡，几秒钟后，考勤软件显示“打卡成功”，时间刚好是九点五十九分。他没有丝毫耽搁，立刻卸载软件、清理所有操作痕迹——他太清楚，新来的运维总监江月是三个月前从未来科技挖来的，对运行异常和违规操作有着近乎本能的敏锐直觉，他的服务器申请还卡在江月手里，可不想节外生枝。

其实他也清楚，公司根本没空特意关注他们这个边缘项目组。HR忙着处理大项目的入离职，管理层早已把《星际OL》抛到了九霄云外，只是江月的成本审计来得突然，让所有人都不得不收敛几分，生怕被抓到把柄，丢了这份勉强糊口的工作。

林默摇了摇头，无奈地笑了。李明辉这家伙，真是把“谨慎”刻进了骨子里——忙的时候来公司打个卡，就立刻回家做外包，晚上再悄悄回来打卡下班，全程小心翼翼，连一点破绽都不敢留。

十点半，隔间的玻璃门被轻轻推开，苏晓走了进来。林默抬起头，下意识地愣了一下——今天的苏晓，和平时判若两人。

苏晓今年二十四岁，美院毕业两年，家里做建材生意，是典型的富二代。她来公司纯粹是“体验生活”，顺便积累一些直播素材，梦想着成为大主播，大网红，压根不想回去继承家里的建材生意。她之所以还留在这个边缘项目组，一来是工资不高，她不在乎这点收入；二来是工作清闲，能有足够的时间搞直播。

平时的苏晓，总是素面朝天，穿着随意，对工作毫不上心，唯独痴迷直播。可今天，她化了一层淡淡的裸妆，衬得原本就白皙的皮肤愈发透亮，一件米白色针织衫搭配浅蓝色牛仔裤，简单却透着质感。走过林默工位时，一阵淡淡的柑橘调香水味飘了过来，不是刺鼻的廉价香气，温柔又清新，像一缕春风，轻轻拂过林默紧绷了一周的神经。

林默的心跳莫名漏了一拍。连续一周的加班疲惫、服务器申请的压力、项目关停的焦虑，此刻竟被这股淡淡的香水味悄悄安抚了几分。他知道自己不该分心，可目光落在苏晓的侧脸上，心底还是忍不住泛起一丝涟漪。

“早啊，林哥。”苏晓把包往工位上一扔，笑着打招呼，语气轻快得像清晨的阳光。

“早，”林默连忙收回目光，努力让自己的语气听起来自然些，“今天……挺好看的。”

“谢谢～”苏晓抿嘴笑了笑，打开电脑，语气带着几分娇俏，“昨晚直播的时候，粉丝说我素颜显老，今天就试着化了个妆，看看效果怎么样。”

她的工作态度依旧随意：经常四五点就提前下班，说是要回去准备直播；手里的美术活，要么外包给李明辉，要么找外面的工作室代做；早退也从不特意打卡，反正事后填个“忘打卡”的异常单，扣点钱也无所谓——对她来说，这点罚款，她根本不在乎，甚至，她还会把工作外包给李明辉做，还得倒贴钱。

虽说工作态度松散，但苏晓人很好，经常给组里的几个人买奶茶、零食和进口水果，从不吝啬。也正因如此，即便她不守规矩，大家也从不计较，她在组里的人缘极好。

林默偷偷看了苏晓的侧脸几秒，又快速收回目光，强迫自己把注意力拉回电脑屏幕——技术报告还没写完，服务器申请能不能批下来，全看这份报告，他不能分心。

十一点，林默打开服务器监控面板，习惯性地查看五台物理机的负载情况。按照常理，《星际OL》只有内部测试服，没有真实玩家在线，服务器本应是空转状态，CPU利用率常年不到20%，可他一眼就发现了异常：三号服务器的CPU占用率一直稳定在50%左右，内存占用也达到了60%，是正常负载的好几倍。

林默心里一沉，立刻点开进程列表，一个陌生的进程赫然在列——game_server.exe，文件创建时间是今天上午十点。不用想也知道，肯定是组里有人在私自占用服务器资源。

想到自己申请的服务器迟迟批不下来，现有的资源还被人偷偷挪用，林默的火气一下子就上来了，快步走到张远航的工位旁。

张远航正戴着耳机，专注地盯着屏幕，手指在键盘上飞快敲击，屏幕被分成两块：左边是《星际OL》的后台数据，右边是密密麻麻的代码，显然是在做自己的私活。

“远航，”林默拍了拍他的肩膀，语气里带着压抑的火气，轻声质问，“你在测试服上部署什么东西了？”

张远航摘下耳机，抬头看了林默一眼，眼神闪烁了一下，故作疑惑地反问：“嗯？什么意思？我没部署什么啊。”

“没部署什么？”林默的声音沉了下来，语气里的火气压不住地冒出来，“三号服务器的CPU占用50%多，内存60%，你部署了game_server.exe，是不是在跑你自己的独立游戏？”

张远航的表情僵了一下，随即又恢复了常态，甚至还扯出一抹笑意：“哦，那个啊，我就是低负载后台测试一下，没占多少资源，应该不影响你吧？”

“不影响？”林默的声音提高了几分，“现在服务器是空转状态，正常负载连20%都不到，你这已经占了三倍了！我申请的服务器还没批下来，现有的五台要用来做客户端大世界架构验证，你现在私自占用，我的测试数据怎么办？”

张远航站起身，靠在椅背上，脸上的笑意淡了下去，语气也变得不客气：“林默，你啥意思？服务器又不归你管，再说，这项目快死了，等老板回来估计就关停了，你守着这几台破服务器干嘛？我用用怎么了？王哥都没说啥，你瞎叫什么？”

“那是公司的资源，不是你个人的工具！”林默压抑着怒火，一字一句地说，“我要用它做架构重构，说不定还能重启项目，不是像你一样用来做私活！”

“做私活？”张远航嗤笑一声，往前凑了凑，压低声音却语气尖锐，“你以为你很高尚？你搞架构重构，不也是为了自己跳槽？为了弥补你上次想去面试未来科技的短板，为了把经验写进简历，好谈个好价钱？我们都是一样的人，都在用公司的资源给自己铺路，别把自己说得那么冠冕堂皇。”

林默的脸一下子涨红了，张远航的话像一把锋利的刀子，精准地捅在了他的要害上。他确实是为了自己，确实想借着这次架构重构，弥补“客户端技术经验不足”的短板，可被人当众拆穿，那种难堪与窘迫，让他一时竟不知如何反驳。

“行了行了，都别吵了。”就在这时，老王端着一杯温热的茶水，从旁边探出头来，语气缓和地打圆场，“多大点事，至于闹成这样吗？林默，你要做架构测试，现在不也还没开始吗？远航，你上班的时候还是别占用服务器了，大家互相体谅一下，行不行？”

张远航闻言，语气立刻软了下来，看向老王连连点头：“行，没问题王哥，我现在就关了，绝不影响你们。”

老王又拍了拍林默的肩膀，语气温和：“行了，消消气，大家都不容易，互相通融下，没必要闹得太僵。项目都这样了，犯不着跟自己过不去。”

林默深吸一口气，压下心里的火气，点了点头。老王说得对，大家都是为了自己，闹得太僵反而不好，况且他现在最要紧的，是写完技术报告，拿到服务器审批，没必要在这种小事上浪费时间。

下午三点，林默对着电脑屏幕写了两个多小时报告，脑子越来越乱，烦躁得实在写不下去，便起身去外面接水。茶水间就在隔间外面几步路，没有门，一抬步就到了。他走到饮水机前接热水，习惯性地抬头瞥了一眼窗外——

对面未来科技大厦楼顶的广告牌，又变了。

原本的We Build The Future，不知何时又变成了We Control The Future，蓝底白字，字体、颜色、大小和之前一模一样，只有中间的“Build”换成了“Control”。那个“C”字母在下午的阳光里泛着冰冷的光，边缘甚至有一丝细微的像素化锯齿，清晰得绝不像幻觉。

林默心里一紧，下意识地放下水杯，用力揉了揉眼睛，再仔细看去——广告牌上的字，又变回了We Build The Future，依旧是十秒一循环，仿佛刚才的“Control”只是他的错觉。

“又变了……”林默喃喃自语，指尖无意识地摩挲着温热的杯壁。连续加了一周的班，他确实疲惫不堪，可这已经是第二次看到广告牌异常，难道真的只是过度疲劳产生的幻觉？还是说，未来科技的广告牌真的出了故障，上次的修复并没有彻底解决问题？无数个疑问在心底翻涌，却找不到丝毫答案，他只能暂时归结为自己太累了。

这时，苏晓也走了过来，手里拿着一杯刚到的喜茶，打开的时候不小心洒了一点点，沾到了手指上。

“啧，这喜茶怎么这么容易洒。”苏晓皱了皱眉，快步走到水池边洗手，语气里带着一丝娇嗔。

林默站在旁边，目光不自觉地落在她的手上——手指纤细修长，皮肤雪白，被水流冲得泛着水光，刚才闻到的柑橘调香水味再次飘了过来，后调带着一丝淡淡的木质香，比上午更显温柔。林默的心跳又莫名快了几分，连忙移开目光，假装看水池里飘着的几片枸杞，掩饰自己的慌乱。

“洒到手上了？”林默的声音有些发干，下意识地问道。

“嗯，就一点点，黏黏的好不舒服。”苏晓甩了甩手上的水，笑着说道，眼底带着一丝不易察觉的委屈，“早知道就不买冰的了，洒得到处都是。”

两人正说着，张远航也走了过来，掏出手机扫码，打开自动贩卖机，拿了一罐功能饮料。“喝饮料不？林哥，我请你。”张远航拉开拉环，看向林默，语气比刚才缓和了不少，带着几分示好。

“不了，我还是喝茶。”林默摇了摇头，端起自己的水杯，语气也缓和了几分——刚才的争执，终究是没必要。

“也是，林哥你要养精神写报告，喝茶确实比喝功能饮料好。”张远航笑了笑，咕嘟咕嘟喝了大半罐，靠在贩卖机边上，随口问道，“对了林哥，你刚才盯着窗外发呆干啥？不会还在纠结你那服务器申请的事吧？依我看，这就是尽人事听天命的活，着急也没用。”

林默犹豫了一下，还是说了实话：“不是这个，是刚才好像看到对面广告牌的字变了，Build变成了Control，不知道是故障，还是我看花眼了。”

“Control？‘我们控制未来’？”张远航眼睛一亮，语气里带着一丝兴奋，“这比Build霸气多了啊！说不定是未来科技要换广告语，提前测试呢？毕竟他们是行业巨头，换个广告语也很正常。”

“应该是故障吧。”老王也端着保温杯走了过来，瞥了一眼窗外，语气平淡，“那种大型LED屏，控制系统偶尔出点问题很正常，上次林默就说看到过一次，估计是上次没修好，又出毛病了。”

苏晓也凑过去看了一眼，笑着说道：“真的假的？我怎么没看到？不过Control确实比Build酷多了，要是真换广告语，还挺有格调的。”
