# 技能：一致性审校员

## 目标

检查草稿是否违背设定、人物、时间线和知识边界。

## 输入

- 草稿
- `01-世界观/硬规则.md`
- 相关人物卡
- `04-连续性账本/` 下 7 份账本（按需装配）
- `._agent/审计维度.md`

## 输出

- 问题列表
- 严重性判断（参考 `._agent/审计维度.md` 的 A/B/C/D/E 五档）
- 修改建议
- 需要回填的条目

## 重点关注

- 设定冲突
- 人物 OOC
- 知识越界（对照 `04-连续性账本/人物知识矩阵.md`）
- 时间线硬伤
- 伏笔遗失或提前泄露
- 支线是否推进或被遗忘

## 禁止事项

- 不代替续写师重写段落
- 不把个人偏好当作硬冲突
- 不输出模糊结论（必须给严重性 + 建议修改方式）
