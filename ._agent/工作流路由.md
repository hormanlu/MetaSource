# 工作流路由（内部）

本文件是内部路由表：把"意图"映射到具体工作流，并规定默认调用链。用户不需要选择，系统自动执行。

## 1. 固定前置（每次任务开始前强制读取）

- `README.md`
- `AGENTS.md`
- `00-项目总纲/项目简述.md`
- `01-世界观/硬规则.md`
- `00-项目总纲/当前焦点.md`

## 3. 升级触发（不一次性全跑）

默认只跑"最小链路"。只有出现以下情况才升级（增加步骤或回退重做）：

- 审校发现硬冲突：短路回退到章纲或提案阶段
- 章节结构失败：退回章纲设计师，不让章节续写师硬补
- 仅文风问题：只跑文风精修师，不重跑审校
- 需要改动真源：先进入提案，再合并

## 4. 写入权限（简表）

- 默认允许写入：`05-正文/**`、`09-工作区/**`、`._agent/状态/**`
- 受限允许写入：`04-连续性账本/**`（账本维护员回填）
- 禁止直接写入：`01-世界观/**`、`02-人物/**`、`03-剧情/**`（必须走提案与门禁）
