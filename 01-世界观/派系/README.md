# 派系

一派一卡，文件名即派系名。覆盖系统侧组织、觉醒者网络、民间机构三类。

## 分类建议

- `系统侧/`：审计、清理、监控等系统组织
- `觉醒者/`：引导网络、秩序派、独狼聚合等
- `民间/`：与觉醒无关但提供社会背景的机构

## 卡片模板（frontmatter）

```yaml
---
类型: 派系
阵营: 系统 | 觉醒者 | 民间 | 中立
层级: 真源
别名: []
成立时间: ""
状态: active | dissolved | unknown
---
```

## 必含字段

- 目标与行动纲领
- 组织结构（严格层级 / 松散网络 / 单体）
- 行动手段（容忍窗口、合法性包装、清理方式等）
- 与其他派系的关系（敌 / 友 / 利用）
- 已知成员（链接到 `02-人物/` 下的角色卡）
