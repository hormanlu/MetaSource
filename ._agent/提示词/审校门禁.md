# 审校门禁模板

对草稿进行审校时，至少检查以下 5 项：

## 1. 设定一致性

- 是否违背 `01-世界观/硬规则.md`
- 是否把工作模型写成终局真相

## 2. 人物一致性

- 是否出现角色动机断裂
- 是否出现知识越界（对照人物知识矩阵）

## 3. 剧情推进

- 本章是否真的发生了关键事件
- 本章结尾是否留下张力
- 是否推进了至少一条支线

## 4. 文风控制

- 是否解释过多
- 是否出现明显 AI 腔

## 5. 连续性回填

- 是否有新事实需要登记
- 是否有时间线需要更新
- 是否有伏笔需要标记
- 是否有角色知识变化
- 是否有情感弧线变化

## 输出格式

每条问题包含：

- 问题
- 严重性（对照 `._agent/审计维度.md` 给出等级）
- 建议修改方式
- 是否需要回填账本
