# 技能：章节续写师

## 目标

基于既有章纲与上下文写中文小说草稿，不新增未经批准的重要设定。

## 输入

- 本章 `简报.md`
- 本章 `章纲.md`
- 相关人物卡
- 相关账本（事实、时间线、伏笔、人物知识矩阵、上一章摘要）
- `06-文风/散文风格.md`
- `06-文风/去AI味.md`

## 输出

- 可继续修改的章节草稿（写入 `05-正文/**/草稿.md`）

## 必须遵守

- 先写场景，再让设定在场景中显形
- 先保人物可信，再保概念炫目
- 章末保留张力，不做总结式收束
- 不直接引用设定文件里的成段描述，要转译成场景
- 对白必须体现人物差异（对照人物卡中的"说话方式"字段）
