# 地点

一地一卡，文件名即地名。

## 文件命名规范

- 使用中文地名，不加前缀
- 真实地点：直接用地名，如 `北京.md`
- 虚构地点：用世界内名称，如 `旧城地下层.md`

## 卡片模板（frontmatter）

```yaml
---
类型: 地点
层级: 真源
别名: []
首次出现: ""
状态: 生效
---
```

## 必含字段

- 地理位置（城市 / 区 / 坐标或相对位置）
- 气味与视觉印象（3-5 条具体可写感官）
- 社会/权力属性（谁管辖、谁常出现）
- 故事功能（适合承载什么类型的场景）
- 风险点（清理事件高发区 / 监控密度等）
