# 觉醒者能力体系（草案 v0.1）

## 通用规则

- 异常值代价：越偏离常规因果，异常值越高，越容易触发系统纠偏或清理伪装。
- 可解释性优先：现实外壳必须成立；能力效果应当能被"现实解释"掩盖。
- 多人一致性：对公共状态的改动需考虑多人同步代价，越多人可见，风险越高。
- 影响范围分层：个人感知 < 小范围环境 < 结构性规则改写，层级越高代价越大。
- 权限不等于安全：短时提权、绕限和读写成功，不代表已经脱离系统审计。
- 任何能力如果反复在同一关系链、同一区域、同一话题上使用，都会把风险从个人异常抬升为网络异常。

## 第一部边界

- 第一部技能上限为 2 级，遵循"真人能力极限上浮一点点"的原则。
- 禁止隔空控制人、读心、改记忆、改意志；禁止直接改结果，仅允许改条件。

## 操作口径

### 物理层遮蔽

- 通过删减表层痕迹、制造记录缺口、切断局部追踪链，为人争取撤离与喘息窗口。
- 优势是快，适合救急；缺点是必然留下更深层的审计残影。

### 系统层合法化

- 不碰表层记录，而是把输入条件、行动路径与输出结果全部放进规则允许区间。
- 优势是稳定且可复查；缺点是推导门槛极高，一旦失败会整链崩塌。

### 诱饵识别原则

- 凡是"过于及时"的机会、"代价过低"的帮助、"权限过高"的通道，都默认先视作诱饵。
- 真正安全的路径通常更慢、更窄、更不舒服，而不是更轻松。

## 林默（逻辑推导 → 读写权限）

### 能力核心

- 通过逻辑链条定位"规则漏洞"，在不破坏系统规则的前提下，为异常行为找到合法路径。
- 不是篡改、删除或伪造日志，而是让输入、过程与输出从一开始就落在可被系统接受的解释区间内。

### 等级与使用场合

- 1级：黑盒异常识别
  - 场合：输入输出不一致、规则边界冲突
  - 影响：仅定位异常，不改变现实
- 2级：改变输入 / 环境
  - 场合：小范围条件改写、场景上下文调整
  - 影响：结果可变，但必须可解释且可合法记账
- 3级：Attach / 改变量
  - 场合：短时读取 / 写入局部状态
  - 影响：异常值显著上升，但仍需维持日志链条自洽
- 4级：局部重构
  - 场合：局部规则替换或重排
  - 影响：风险最高，必须保证"全局可解释"与"系统检测合法"

### 代价与风险

- 精神负载上升，进入"被注视感 / 被校验感"
- 过度使用易触发系统纠偏或清理伪装
- 本质上是在规则内通行，因此上限极高，但一旦推导失误，反噬会直接落到整条合法性链路上
- 林默式路径最怕的是"把伪装成合法的路径误判为真正合法的路径"，一旦信错样本，会被系统借审计回查整片网络

## 顾盼（视觉捕捉）

### 能力核心

- 捕捉光影、边缘、纹理、反射中的"缓存 / 刷新"异常。

### 使用场合

- 识别视觉错位、反光更新延迟、边缘阴影不一致
- 为异常链路提供"可视化证据"

### 代价与风险

- 视觉疲劳、过敏式聚焦
- 情绪波动会放大观察偏移，容易被监测捕捉

### 新版补充

- 顾盼的触发源改为三月底大范围蜃景事件
- 顾盼在桥边事件前后已出现人格分裂式不稳定前兆

## 温启山（秩序觉醒 / 结构识别型）

> **待重写**：按"消熵 / 隐匿行踪 / 以身吸熵"方向重定位；当前文本为旧稿，下轮处理。

### 能力核心

- 对现实自洽性、记录缺口、叙述链裂缝和"被修补过的正常"异常敏锐。
- 在识别异常之后，可进一步以提升权限、绕过限制、清理日志和记录等方式，为觉醒者做现实层的痕迹遮蔽与链路清理。
- 这是一种林默能力的下位版本：能把人暂时藏起来，却不能从系统规则层面让一切天然合法。

### 使用场合

- 识别边缘者是否已站到裂缝边上
- 判断现场记录、监控、证词与现实现象是否被同步修补
- 作为组织现实接口型高层进行低烈度接触与现实止损
- 清除局部监控链、打断追踪链、制造可解释的记录缺口
- 为组织争取撤离、转移与降密度时间窗口

### 首次觉醒契机

- 在一次救援现场发现"明明存在过、却被现实与记录一起擦掉的人"

### 代价与风险

- 长期透支会削弱其对"正常"的信任
- 越靠近裂缝与异常，越容易将责任不断往自己身上揽
- 每一次清链都不会真正消灭异常，只会把异常向系统底层推移，形成持续熵增
- 熵增累计后，系统会以更高权限、更高密度的方式持续追踪和升级监控，这也是温启山后期越来越遮盖不住的根本原因
- 最危险的不是清链失败，而是系统反过来借一次清链读取操作者背后的整张关系图

## 许晋川（帧落 / 失真感知）

### 能力核心

- 感知对象与环境之间的同步失败（帧落）与更深层失真。

### 使用场合

- 预警关键节点失同步
- 判断人是否在"受力集中"状态

### 代价与风险

- 过度感知会引发自身失同步体验
- 容易被误判为"过度敏感"或"神经性应激"

## 徐知远（疑似高阶代理）

### 观察性结论

- 输出稳定得异常，具备模板化与同步性特征
- 月末维护规律与"状态恢复速度"异常吻合

### 叙事限制

- 暂不下定性结论，需更多样本验证
- 现实外壳需保持可解释：过劳 / 维护 / 体检 / 调岗

## 使用边界（叙事约束）

- 同一章内不展示两次"同级别硬改写"，避免破坏真相延迟
- 关键能力的外显需有现实解释壳
- 能力提升需伴随"代价上升"的可感知后果
