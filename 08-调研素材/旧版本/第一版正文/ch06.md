# 第六章 虚实之间（定稿）

那张写着微信号的便签纸，被林默小心翼翼地夹进了笔记本里。

周二晚上回到出租屋，他掏出便签纸压平在桌上，对着那串数字看了片刻，便不再犹豫，拿起手机添加上了微信。对方头像是一个很普通的远景，一个中年男人抱着女儿在海边。昵称只有一个“贺”字，通过申请后，只发来一句简洁的回复：“江总跟我说了。你明后两天准备下，周五上午十点半，来未来科技大厦六十楼前台报到，技术面在五十楼。”

林默盯着屏幕愣了两秒，心跳骤然加快——这不是梦，是他这几年职业生涯里，离“未来科技”最近的一次。他立刻回复“收到，谢谢老师”，发完才察觉这称呼太过拘谨，可早已过了撤回时限，只能暗自懊恼了一下。

周五之前还有两天，林默彻底切换到高压状态，拼尽全力想要抓住这个机会。周三、周四，他依旧按时去星辰大厦打卡，只是工位区每天都空荡荡的，大家打完卡便匆匆散去，连往日那份敷衍的冷清都消散无踪。他没心思探究同事们的去向，只顾着埋头刷题、复盘大世界架构，晚上回到家，又接着整理笔记，拆解之前的服务器申请报告，一点点梳理过往工作中留下的技术漏洞。

周四深夜，笔记终于整理完毕，林默才得以拿起手机。打开微信，屏幕弹出的技术公众号推送和群聊消息里，全是关于XClaw的讨论——各家大公司争相推出相关产品，连未来科技也有动作。他匆匆扫了一眼便关掉页面，实在没时间细究，眼下最重要的，是周五的面试。

周五上午，林默提前四十分钟抵达未来科技大厦楼下。春日的阳光落在玻璃幕墙上，折射出冷亮的反光，让这座六十层的大厦更显压迫感。他抬头望向楼顶那行“ We Build The Future”的广告牌，从前的遥远与挫败感渐渐褪去，取而代之的是一种不真实的具体感，仿佛那曾遥不可及的未来，此刻就触手可及。

前台登记、刷临时访客码、换取证件，整套流程高效得近乎冷漠。六十楼的等候区宽敞而安静，林默坐在靠窗的位置，下意识望向不远处的星辰大厦。从这个高度俯瞰，二十层的星辰大厦显得格外矮小，他的目光落在十七楼自己曾经的工位区域，隐约看见那张早已离职的李明辉的桌上，竟还摆着从前的电脑——他心里猛地一怔，那张桌子怎么还会有东西？但很快，他又自嘲地笑了，距离太远，视线本就模糊。李明辉早就离职，电脑理应早就退库了，大概是玻璃反光造成的错觉吧。

没等他再多想，身后传来一道平稳的男声：“林默？”他回过头，只见一个三十多岁的男人站在不远处，身着浅灰衬衫，手里夹着平板，语气干脆：“跟我来吧，先去五十楼。”林默收回视线，连忙跟上对方的脚步，往电梯方向走去。

五十楼的会议室简洁利落，长桌、屏幕、几台连着扩展坞的笔记本整齐摆放，空气里飘着淡淡的咖啡香气。给他面试的是两位男士，进门后便主动自我介绍，分别是项目主程和技术组长，两人都不算年长，说话干脆利落，显然提前仔细看过他的简历和相关文档，没有多余寒暄，直接切入了正题。

“你在材料里提到，想用 UE 的 World Partition 做大世界重构。假设现在地图规模不变，但服务器资源缩减到原计划的一半，你最优先调整哪几块？”

林默起初还有些紧绷，可一谈及技术，心态反倒慢慢平稳下来。他逐层拆解自己的思路，从地图网格的划分方式，到热区与冷区的加载策略，再到客户端预取、对象状态同步和资源池的取舍，还主动提起《星际OL》内部测试失败的反例，细致地剖析各类问题的症结所在。

面试官的提问越来越细致：“如果角色在分区边界高速移动，客户端预测先于服务端校验，会出现什么问题？”“同一片区域里，静态资源和动态交互对象混合加载，最容易出现故障的节点在哪儿？”“低配机器上内存吃紧，优先删除对象、删除贴图，还是调整渲染层级？”

林默一一认真作答，额头渐渐沁出薄汗，手心也变得有些湿润，但思路始终清晰。他的答案没有照搬书本理论，全是从一次次失败和复盘里踩出来的实战经验，反倒更显真实可信。中途，主程点开他那份服务器申请报告的附件，翻到架构图，抬头问道：“这一版设计里，你把很多对象状态同步拆得很细。现在XClaw这类AI编程工具也能实现这个逻辑，而且效率更高，甚至很多公司用AI做代码生成、代码审查和性能调优，你觉得你做的这些工作，核心价值在哪里？”

林默沉思了几秒，缓缓开口：“AI确实能提升效率，也能替代人完成重复代码编写、常规优化这类耗时间的工作，但程序员的价值，从来不止于敲代码。更重要的是理解系统底层逻辑、排查异常问题，明确优先级，知道该优先解决什么、暂缓什么，当工具失效时，能在混乱中理清思路、找到破局点。”

主程愣了一下，随即露出一丝笑意，在平板上快速记录了几句。接下来的提问中，穿插了几道与AI工作流相关的内容，林默答得有些磕磕巴巴，却也勉强清晰地表达了自己的观点，他并不知道，未来科技早已在大规模应用这类AI工具。

技术面持续了将近一个小时，结束后，两位面试官客气地让他稍作等候，说项目制作人还想和他聊几句。林默的心依旧悬在半空，即便技术面发挥尚可，只要没有明确结果，一切就都还是未知数。

五分钟后，一个四十岁上下的男人推门进来，穿着比技术面试官随意些，气质却更显沉稳。他坐下后，没有多余寒暄，直接问了几个务实的问题：是否接受外包身份、能适应什么样的工作强度、能否从外围模块做起。林默一一如实回答，聊到最后，对方扣下平板，随口补了一句：“好了，我这边没问题了，你有什么想问我的吗？”

林默犹豫了一下，小心翼翼地开口提问，生怕显得太过冒失：“我想问一下，这个外包岗位，主要负责什么工作？”

“哦，你这个岗位原本是不存在的。”林默的心猛地一动，只听对方继续说道：“是江总那边打了招呼，我们才临时加了一个外包名额。简单来说，就是同岗不同薪，你的劳动合同不会和未来科技直接签订，但可以全程参与这个项目的工作。”

“江总……江月？”林默怔怔地重复了一遍，下意识摇了摇头，他对此一无所知。他原本以为，只是这边刚好有岗位空缺，江月只是顺手做了一次内推而已。

制作人见他一脸意外，淡淡笑了笑，解释道：“江总以前是我们事业部的副总裁，分管技术架构、平台、运营这些板块，我都要向上汇报两级才能到她。你应该知道，我们事业部是公司最挣钱的游戏事业部，江总在任时，把我们事业部的技术底子打得非常扎实。”

林默一时语塞，脑子里那个在星辰运维办公室里、语气冷淡、凡事只看结果的总监，与制作人口中分管核心业务、位高权重的江月，始终无法重合。他愣了几秒，终究按捺不住好奇，问道：“那她……为什么会去星辰？”

制作人耸了耸肩，语气带着几分无奈：“这个我不好替她回答。反正她做决定一向不按常理出牌，你要是有机会，不妨自己问她。”

说完，制作人看了眼时间，站起身来：“今天就这样吧，结果不会当场公布，流程还需要走一走。你回去等通知，今天是周五，快的话下周，慢的话两到三周，HR会主动联系你。”林默连忙起身道谢，走出会议室时，脑子里依旧乱糟糟的，面试的细节、江月的身份、外包名额的来龙去脉，一堆信息搅得他难以理清。

乘电梯回到六十楼等候区，他又下意识望向星辰大厦，十七楼那片区域依旧模糊，刚才误以为有电脑的工位，此刻看起来依旧隐约有影子。他又自嘲地笑了笑，暗自想着，早就该配副眼镜了，弄得看什么都模模糊糊的。

就在这时，手机震动了一下，是顾盼的回复。早上面试结束后，他鼓起勇气给顾盼发了微信，问她晚上下班后能否一起喝杯咖啡，此刻屏幕上跳着一行简单的字：“可以的，7点见。”

林默悬着的心稍稍放下了一半，连忙回复：“好的，不见不散。”

顾盼很快回了个小松鼠抱松果的表情包，便没有再继续聊下去。

下午的几个小时过得格外漫长，林默没有回星辰的工位，找了家快餐店随便吃了点东西，便一直坐在店里，反复回想面试时的每一个回答，越想越没底，可心底又忍不住生出几分期待。

直到快六点，他才起身返回星辰大厦打卡，没什么胃口再吃东西，便坐在自己的工位上，静静等到七点。期间，他隐约看到老王、张远航和苏晓三人，先后在六点前站在门口打完卡就匆匆离去，连工区的门都没进。

心里有些急躁，还没到七点，林默就提前动身去了约定的咖啡店。小店靠在街角，玻璃门擦得干净透亮，傍晚的余晖洒在木桌上，映出一道浅金色的轮廓，空气里混杂着咖啡豆的醇厚与奶泡的香甜，节奏舒缓的英文歌轻轻萦绕在耳边，格外治愈。

林默平时并不爱喝咖啡，只是一时想不出更合适的见面地点，又觉得咖啡店氛围温和，便约在了这里。他也不清楚顾盼的喜好，只能走一步看一步。

没想到，顾盼比他到得还要早，正坐在靠窗的位置上，没有背平板，只带了一个浅色的帆布包，桌上放着一杯刚点好的拿铁。看到林默进门，她自然地笑了笑，轻声说道：“来啦，还挺准时。”

“还行。”林默在她对面坐下，脸颊微微发烫，语气里带着几分不易察觉的尴尬，顿了顿，便起身说道：“你先坐着，我去点杯东西。”他走到前台，犹豫了片刻，最终还是点了一杯和顾盼一样的拿铁——毕竟不清楚她的喜好，跟着点总不会出错。

端着拿铁回到座位时，顾盼正支着下巴望向窗外，见他坐下，才收回目光，笑着开口，语气自然又带着几分好奇：“今天怎么有空约我？平时这个点，你不都在星辰加班吗？我路过好几次，你们工区的灯都亮到很晚。”

林默握着杯壁的手紧了紧，脸上的尴尬更甚，沉默了两秒，才轻声解释道：“我们项目……被裁撤了，我下周就正式离职了。今天是去未来科技面试，刚结束没多久，就想着约你出来坐会儿。”

顾盼脸上的笑意淡了些，眼神里掠过一丝明显的讶异，却没有追问太多，只温和地说道：“原来是这样，辛苦你了。面试还顺利吗？”

“说不准，”林默苦笑一声，喝了一口拿铁，温热的液体滑过喉咙，稍稍驱散了心底的不安，他主动说起面试的事，“技术面加制作人面聊，差不多耗了一整天。题目比我预想的要细，尤其是大世界和性能优化那块，后面还聊到了AI编程，现在XClaw不是很火吗，面试官问我怎么看它对程序员的影响。”

“AI编程？”顾盼微微挑眉，没有打断他，安静地听着他继续说下去。

“嗯，”林默又喝了一口拿铁，理清思路后继续说道，“我说AI能做重复的工作、提升效率，但替代不了程序员，毕竟系统异常排查、逻辑梳理这些事，还是得靠人来做。对了，我今天才知道，我们以前的总监江月，以前是未来科技的，职位还不低，真没想到她会去星辰。”

顾盼轻轻“嗯”了一声，神色依旧平静——她本就不认识江月，自然也谈不上惊讶。

“我是真的想不通，”林默低头笑了笑，笑意里满是困惑，“她放着未来科技这么好的位置不干，跑去星辰当一个运维总监，到底图什么啊？”

顾盼沉思了片刻，温和地说道：“有些人不一定喜欢待在完善的系统里安于现状，越是难啃的骨头、越是混乱的地方，对他们来说，可能反而更有吸引力。就像有些人，明知道项目快撑不下去了，还是会拼尽全力把底层架构补好，图的也不只是一份工资而已。”说着，她冲林默笑了笑，眼神里带着几分理解。

林默怔了怔，一时没有说话，顾盼的话，恰好戳中了他心里最真实的那部分——他死守到项目最后，从来都不只是为了工资。

就在这时，店门传来一声轻微的风铃脆响，林默下意识抬头，视线瞬间定格在门口——黑色西装、利落短发、清冷的侧脸，分明就是江月。他本能地绷紧脊背，手扶住桌边，几乎要站起身来，脑子里乱糟糟的，闪过无数个念头：她怎么会在这里？该主动跟她打招呼吗？该好好跟她说声谢谢吗？

可下一秒，他就僵住了——玻璃门安安静静地关着，金属拉手一动未动，门外人来人往，刚才那道身影，不过是逆光下一个身形相似的路人。

林默慢慢坐回原位，有些尴尬地挠了挠头，脸上满是窘迫。顾盼看在眼里，低声问道：“怎么了？认错人了？”

“嗯，”林默苦笑了一下，有些无奈地说道，“刚才好像看到江月了，明明觉得轮廓很像，再细看才发现不是。可能是今天脑子里全是她的事，太恍惚，看花眼了。”

“很正常，”顾盼笑了笑，没有多追问，语气温和地安慰道，“逆光加上玻璃的反射，很容易看错人。”

林默点了点头，自己打了个哈哈，缓解尴尬：“可不是嘛，估计是我脑子太乱了，就像我们写程序的时候，经常会出现对象加载错误一样。”说完，他突然意识到顾盼可能听不懂这话，连忙补充了一句“抱歉，职业习惯”，脸上泛起几分红晕，有些不好意思地笑了。

顾盼顺着他的话笑了笑，没有追问，轻轻转着手中的咖啡杯，问道：“那你现在最放不下的，是面试结果，还是江月的事？”

“都有吧，”林默靠在椅背上，望向窗外的夜色，语气里带着几分茫然，“面试肯定希望能过，但江月这个人，我是真的没看懂。她为什么要帮我，为什么要放弃未来科技的好职位去星辰，全是疑问。”

“慢慢来就好，”顾盼轻声说道，语气里满是温柔，“很多人和事，都不是一时半会儿就能看懂的，时间久了，自然会有答案。”

两人又聊了一会儿，顾盼说起自己的公司，大概是去年底搬进星辰大厦的，听说星辰去年裁了不少人，空出了两层，而她们公司和未来科技有很多合作，便把一部分对接的团队安置在了这里。林默听着，心里莫名一动——大环境确实不好，可转念一想，若是自己能顺利通过面试，以后和顾盼说不定还有更多合作、更多接触的机会。可看着顾盼身上那种自然得体的分寸感，他又觉得自己想多了，心底还生出几分愧疚，脸颊不由得又红了起来。

咖啡喝到快八点，两人才起身准备离开，顾盼说自己还有事，便先一步道别，转身匆匆离去。夜色已深，街边的路灯次第亮起，未来科技大厦的玻璃幕墙映出成片冷光，星辰大厦则渐渐退回了普通的城市背景里，显得安静而矮小。

林默站在路边，望着顾盼离去的方向，她的背影平稳从容，每一步都踩在自己的节奏里，温柔却有力量。他心里忽然冒出一个直觉：顾盼好像总能在他困惑、窘迫的时候，给出一个刚好够用的安慰，不多一分，也不少一分，恰到好处地缓解他的尴尬。

这个念头一闪而过，很快就被面试结果的焦虑取代。他抬头望向未来科技楼顶的广告牌，那句“We Build The Future”在夜色里格外明亮。他忽然觉得，自己正站在新旧人生的分界线上，往前，是充满未知的新区域；往后，是早已清空、只剩回忆的旧过往。而他，只能硬着头皮，一步步往前走去——这和他做的大世界方案何其相似，只有清理掉旧的冗余，才能顺利加载新的场景。

他拢了拢身上的外套，压下心底的忐忑，转身往地铁站的方向走去。

与此同时，五十楼那片落地窗前，早上林默曾站过的地方，夜色正缓缓铺展开来。视线的尽头，星辰大厦十七楼那处林默上午看到有电脑的工位，极快地闪了一下，瞬间恢复成了彻底清空后的模样，清晰可见，但时间短得却像一帧未及时刷新的画面。
