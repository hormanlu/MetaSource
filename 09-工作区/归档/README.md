# 归档（软删除仓）

本目录等价于 Scrivener 的 Trash：**永远不用 `git rm` 删除创作产物**，一律移入本目录。

## 归档规则

- 被替换的旧版设定：移入 `设定/<名称>-<日期>.md`
- 被砍的章节：移入 `章节/<章号>-<日期>/`
- 作废的提案：移入 `提案/<名称>-<日期>/`
- 过期的灵感：移入 `灵感/<日期>/`

## 为什么不删

- 旧版本可能在未来用于对照
- 被砍的桥段可能在续卷里重新拾起
- 设定演化历史本身就是 IP 资产
- Git 检索历史成本远高于目录浏览

## 不归档的情况

- 纯粹格式错误、重复文件、临时测试文件：可以直接 `git rm`
- 本目录本身不放在任何工作流中被读取
